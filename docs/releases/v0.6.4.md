## 0.6.4

设置页「XTS报告上传」插件的完整可用版本：评测资料提交（第 1→5 步）、豁免草稿、镜像固件上传三条链路都已对着真实平台跑通。

### 评测资料提交（第二阶段）

- **产品定义改为推进式提交**：`isSave:false` 才会让平台生成第 4 步的报告关联行；此前只保存（`isSave:true`）会导致第 4 步永远是空列表、卡在 `REPORT_RELATION_MISSING`。
- **报告上传跑通**：`report/report.zip` + PCS 自检表上传、`saveTestReport` 写回、镜像文件选择、`saveReport` 推进到第 5 步。
- **样机寄送跑通**：从设备目录自动取 `OpenHarmony兼容性测试样品清单.xlsx` 上传，工作簿填了「快递单号」就自动保存第 5 步；幂等（平台已一致则跳过）。
- **预检自动打包**：`report/` 目录没有 zip 时按需打成 `report/report.zip`，已是最新则复用，人工放的 zip 不会被套娃。
- **旧版式工作簿自动升级**：读表前就地升级（补「内核」行并按系统类型填 Linux / LiteOS-A / LiteOS-M，去掉「外观图路径」「PCID.sc 路径」两行）；WPS/Excel 占用时只给提示不阻断。
- **外观图与 PCID.sc 按设备目录自动定位**，工作簿不再需要这两行；旧表仍可读。
- **只填设备目录即可**：自动带出 `exemption/`、固件包、`OpenHarmony兼容性申请资料.xlsx`；该行只收目录，不会被替换成文件名。
- **未提交草稿面板**：列出目录下能继续提交的申请（`phase2/drafts`），点「评测资料提交」会续那条申请而不是重复新建。

### 镜像固件上传

- `.zip` / `.7z`（也接受 tar 系列）路径 → 平台「企业空间 → 镜像管理」，进度实时同步（解析 / 上传 / 校验三段）。
- **同名去重**：平台已有同名且已传完的固件直接跳过（实测 13.8s vs 正常 230s）；未传完则续传补齐。
- **历史重复提醒**：同名记录 >1 条时面板上黄色提示，只提示不删除。
- 预检通过后自动接上固件上传（不再需要手动点两次）。

### 豁免资料

- 按 `Acts` / `ActsValidator` / `Hats` / `Dcts` / `Ssts` 目录自动识别测试套分类与平台提交路径，HATS/DCTS/SSTS 已预留。
- 附件优先 `<套件>-豁免材料.zip`，缺失时直接用该套件的 `.txt`。
- 只保存草稿，绝不提交；任一条失败即停。

### 安全补丁日期

- 统一按平台格式 `YYYY/MM/DD` 发送，`2026-11-1`、`2026.1.5`、`20261101` 都会自动归一；回读比对两侧都归一，不会只因分隔符误报。

### 设置页

- 卡片按 DSH 主题令牌重写，深浅色一致；窄屏单列。
- 说明收紧为一句话，长解释下沉到字段 hint。
- 每条失败都给可执行提示（宿主半区未重启、平台 500 引用已删镜像、重复设备等）。
