## 1.0.0 第一个正式版

一个 DSH 插件：给它一个设备目录，它把设备的兼容性资料和固件交给 OpenHarmony 兼容性平台，存成「未提交」草稿。

- **评测资料提交**：自动识别工作簿与附件，跑完平台第 1→5 步（联系人 / 产品 / 软件 / 报告 / 样机寄送），把测评编号写回工作簿。
- **镜像固件上传**：给 `.7z` / `.zip` 路径或目录，按文件名查重，平台已有就跳过，上传进度实时显示。
- **豁免资料**：按目录识别测试套分类与平台提交路径，批量存成草稿。
- **只保存草稿**：不代点「确认提交」，不删除平台记录，凭据只留在本机。

装完重启 DSH Desktop，设置 →「XTS报告上传」即可使用。
